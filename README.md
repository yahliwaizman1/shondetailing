# Shon Detailing Demo

Premium one-page demo website built from the supplied catalog screenshots.

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Deploy to Vercel
Import the repository into Vercel. Vite is detected automatically.
